# Essentia + AMN Patient Journey to Language Access Microsite

Interactive demo microsite for Essentia and AMN Healthcare.

## Live Demo

After enabling GitHub Pages (Settings → Pages → Deploy from `main` branch), the site will be available at:

`https://coreyboltamn.github.io/essentia-patient-journey-language-access/`

## What this includes

- Co-branded landing page
- Interactive patient journey timeline
- Scenario-based path selection
- Agenda-aligned section explorer
- End-to-end urgent care walkthrough
- Reporting and implementation overview

## Local preview

Open `index.html` directly in your browser or run a static server:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
